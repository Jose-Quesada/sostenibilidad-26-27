## 1. Glosario de términos

### Sostenibilidad (general)

| Término | Definición breve |
|---------|------------------|
| **Sostenibilidad** | Capacidad de un sistema de mantenerse en el tiempo sin degradarse. |
| **Desarrollo sostenible** | Satisfacer necesidades presentes sin comprometer a las generaciones futuras (Brundtland, 1987). |
| **Transición ecológica** | Camino para pasar del modelo actual a uno sostenible (en la UE, motorizado por el Pacto Verde). |
| **Triple dimensión / tres pilares** | Ambiental + social + económico/gobernanza. |
| **ASG / ESG** | Aspectos Ambientales, Sociales y de Gobernanza (*Environmental, Social, Governance*). |
| **Materialidad** | Grado en que un tema ASG es relevante para una empresa (afecta al valor o es afectado por él). |
| **Doble materialidad** | Analizar el impacto del negocio en el mundo (temática) y del mundo en el negocio (financiera). |
| **Greenwashing** | Comunicación que exagera o falsea el desempeño ambiental/ASG de una empresa. |
| **Stakeholder / grupo de interés** | Persona u organización afectada por o que afecta a la empresa. |

### Marco internacional y ODS

| Término | Definición breve |
|---------|------------------|
| **Agenda 2030** | Plan de la ONU (2015) con 17 ODS y 169 metas para 2030. |
| **ODS** | Objetivos de Desarrollo Sostenible (17). |
| **Acuerdo de París (2015)** | Régimen climático: limitar el calentamiento a 1,5–2 °C mediante NDC. |
| **NDC** | Contribución Determinada a Nivel Nacional (compromiso climático de cada país). |
| **Pacto Verde Europeo** | Estrategia UE para la neutralidad climática en 2050. |
| **Taxonomía UE** | Clasificación de actividades económicas "ambientalmente sostenibles". |

### Emisiones y huellas

| Término | Definición breve |
|---------|------------------|
| **GEI** | Gases de Efecto Invernadero (CO₂, CH₄, N₂O, HFC…). |
| **tCO₂e** | Toneladas de CO₂ equivalente (unidad de emisión). |
| **Alcance 1** | Emisiones directas (combustión propia). |
| **Alcance 2** | Emisiones indirectas por energía comprada. |
| **Alcance 3** | Resto de la cadena de valor (más amplio; suele ser el mayor en TIC). |
| **Huella de carbono** | Total de GEI asociados a una actividad/producto/organización. |
| **Huella hídrica** | Volumen de agua consumido a lo largo del ciclo de vida. |
| **Neutralidad neta (net zero)** | Reducir emisiones al mínimo y compensar el resto. |

### Economía circular y ecodiseño

| Término | Definición breve |
|---------|------------------|
| **Economía lineal** | Extraer → producir → usar → tirar. |
| **Economía circular** | Eliminar residuos, mantener valor de productos/materiales, regenerar naturaleza. |
| **Economía verde** | Crecimiento que reduce el riesgo ambiental y mejora el bienestar. |
| **Ecodiseño** | Integración de criterios ambientales desde el diseño, a lo largo del ciclo de vida. |
| **LCA (ACV)** | Análisis del Ciclo de Vida: impactos en todas las etapas (ISO 14040/14044). |
| **Reacondicionado / remanufactura** | Restaurar un producto usado a estado funcional/cercano a nuevo. |
| **RAEE / WEEE** | Residuos de Aparatos Eléctricos y Electrónicos. |

### Estándares, métricas e inversión

| Término | Definición breve |
|---------|------------------|
| **GRI** | Global Reporting Initiative: marco global de reporte de sostenibilidad. |
| **SASB / ISSB (IFRS S1-S2)** | Estándares de materialidad financiera y divulgación climática. |
| **CDP** | Carbon Disclosure Project: calificación a inversores (clima, agua, bosques). |
| **TCFD** | Divulgación financiera relacionada con el clima (4 pilares). |
| **ISO 14064 / GHG Protocol** | Cuantificación e informe de GEI. |
| **ISO 50001 / 14001** | Gestión de energía / gestión ambiental. |
| **PUE** | Power Usage Effectiveness: eficiencia energética de un data center (total/IT). |
| **WUE** | Water Usage Effectiveness: litros de agua por kWh en un data center. |
| **ISR** | Inversión Socialmente Responsable (integra criterios ASG). |
| **KPI** | Indicador clave de desempeño. |

### Normativa

| Término | Definición breve |
|---------|------------------|
| **CSRD** | Reglamento UE de reporte de sostenibilidad (doble materialidad + ESRS + aseguramiento). |
| **ESRS** | Estándares Europeos de Reporte de Sostenibilidad. |
| **SFDR** | Regl. de divulgación de sostenibilidad en finanzas. |
| **CSDDD** | Debida diligencia en derechos humanos y medio ambiente (cadenas de valor). |
| **RoHS / REACH** | Restricción de sustancias peligrosas / registro químico. |
| **RGPD / NIS2** | Protección de datos / ciberseguridad (gobernanza tecnológica). |

## 4. Soluciones orientativas a los cuestionarios

> Pistas breves para autoevaluación (no son respuestas cerradas; el alumnado debe desarrollarlas).

**Archivo 01.** Brundtland: necesidades presentes sin comprometer futuras; pilares E/S/G. La
sostenibilidad es el estado, el desarrollo sostenible el proceso y la transición ecológica el
camino concreto. ODS prioritarios TIC: 7, 9, 12, 13 (y 6, 5, 8, 10, 16 según empresa). CSRD obliga a
reportar doble materialidad con aseguramiento. Materialidad financiera = cómo el ASG afecta al valor;
temática = cómo la empresa afecta al mundo.

**Archivo 02.** E (emisiones/energía/residuos), S (laboral/privacidad/ética IA), G (transparencia/
ciberseguridad/cadena). La gobernanza tecnológica es propia del sector porque el producto *es* datos y
software. Matriz poder/interés: clientes e inversores suelen estar en "gestionar de cerca". Los
aspectos materiales de HP (residuos) difieren de Microsoft (energía de cloud) por su modelo de negocio.

**Archivo 03.** ISO 14064 mide GEI; GRI el reporte integral; IFRS S2 la divulgación climática-financiera.
PUE = total/IT → 1200/1000 = **1,2**. KPIs: E (tCO₂e, % renovables, PUE), S (% mujeres técnicas,
nº incidentes), G (comité ESG, % proveedores auditados). Screening negativo excluye; impacto busca
resultado medible. Una mala MSCI encarece el capital y alea flujos de inversión responsable.

**Archivo 04.** Retos ambientales: energía/GEI, agua, RAEE, minerales críticos, obsolescencia. Sociales:
brecha digital, cadena laboral, privacidad, ética IA, género. El sector es fuente (consume) y palanca
(digitaliza para ahorrar). Huella hídrica de data center: refrigeración cerrada, reutilización, ubicación
en zonas con excedente hídrico/energético. Alianza público-privada: smart city eficiente (gana planeta,
personas y economía).

**Archivo 05.** Modelo lineal del portátil: extracción de minerales → fabricación (chips) → uso
(energía) → vertedero. Principios circulares: eliminar residuos (diseño sin tóxicos), mantener valor
(reparación/reventa), regenerar (renovables). Ecodiseño de servidor: eficiencia energética, durabilidad,
desmontaje fácil, materiales reciclados, renovables. LCA cloud: la fase de uso (energía) domina.
Software verde: algoritmos optimizados, consolidación, región con renovables, IA destilada.

**Archivo 06.** Huella personal: teletrabajo, apagar equipos, compra duradera, reciclaje RAEE. KPIs data
center: PUE, WUE, % renovables, tCO₂e. Software verde: optimización de BD, caché/compresión, región verde.
Fin de vida de servidor: RAEE (Ley 7/2022 / RD 110/2015), operador autorizado, borrado de datos. Ecodiseño
UE: eficiencia, durabilidad, índice de reparabilidad, repuestos.

**Archivo 07.** Stakeholders cloud: empleados, inversores, clientes, proveedores, regulador, comunidad,
ONG, prensa. Aspectos materiales: GEI (afecta a coste/valor y al clima), residuos (RAEE + reputación),
privacidad/IA (legal + confianza). KPIs: tCO₂e (ISO 14064), PUE (GRI 305), % renovables (CDP), kg RAEE
(GRI 306). Índice informe: carta dirección, modelo negocio, materialidad, estrategia, desempeño E/S/G,
brechas, metas, aseguramiento.

## 5. Sugerencias de profundización (opcional)

- **Cursos/certificaciones:** introducción a GRI, ISO 14064, PUE/WUE (Green Grid), análisis LCA.
- **Proyectos reales:** participar en la elaboración del informe ASG de una empresa colaboradora.
- **Competencias TIC verdes:** "green software engineering", eficiencia energética de data centers.
- **Seguimiento normativo:** evolución de CSRD/ESRS y del reglamento de ecodiseño (actualizaciones).
